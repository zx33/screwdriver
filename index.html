项目说明

一把工具，解决一个小麻烦

今天，拧哪颗螺丝？

对一遍修改，转一份文档，或给 Mac 菜单栏腾点空间。
选好工具，就可以开始。

MΔ 浏览器工具

Markdown Review

把两份 Markdown 放在一起，看清每一处修改。

  • 行内修订与源码并排
  • 按词或按字符查看差异
  • 修改统计与逐处跳转
开始对比 ↗ 使用说明
MW 浏览器工具

Markdown → Word

粘贴或拖入 Markdown，生成能继续编辑的 Word 文档。

  • 保留标题、列表和表格
  • 即时排版预览
  • 在浏览器本地导出 .docx
转换文档 ↗ 使用说明
⌄ macOS 13+ · 原生应用

Mac Stats Bar

在 Mac 菜单栏里，查看系统状态与 Codex 剩余额度。

  • CPU、内存、网络等系统指标
  • Codex 额度与恢复时间
  • 菜单栏图标收纳预览
查看工具 ↗ 构建与使用

文档工具可直接在浏览器中使用，内容留在本地。Mac Stats Bar 需要在 Mac 上构建并运行。
