# 初版历史验证记录

本文来自迁入前的独立 `mac_stats_bar` 仓库，描述 `57f8079` 初版，保留作为历史证据。本次迁入结果见 [integration.md](../integration.md)。

验证日期：2026-09-15。环境：macOS 15.1.1、Apple Silicon、14 核、48 GB 内存；Apple Swift 6.0.3。

## 结果

- Release 构建成功；应用包约 1.06 MiB，临时签名校验通过。
- 18 项核心检查通过，0 失败。测试使用无第三方依赖的 Swift 检查程序，可在不包含 XCTest 的 Command Line Tools 环境中运行。
- 真实系统采样成功：CPU、内存、上下行速率、磁盘可用空间、电池及供电状态、散热状态。
- 本机 Codex CLI 0.153.4 的独立只读额度请求成功；覆盖多额度组、窗口与重置卡的读取。个人账户的实际窗口、余量和重置卡读数已从公开记录移除。
- 原生面板实测：系统数值变化、偏好设置、内存显示开关（已恢复默认关闭）、暂停 / 恢复、整行展开其他额度、手动同步、面板关闭与重新打开。
- 默认 5 分钟自动同步已实际发生：界面成功同步时间由 11:31 更新为 11:36，无手动刷新操作。
- 点击退出后，被测试应用进程正常结束，退出码 0。最后另行重新打开应用供使用。

## 资源测量

| 场景 | 观察结果 |
| --- | --- |
| 关闭面板，系统每 5 秒、额度每 5 分钟 | 观察 30.63 秒；平均 CPU 0.131%（单核口径）；RSS 70.45–70.52 MiB |
| 同一后台观察窗口 | 查询子进程数量 0 |
| 单独执行一次系统与额度诊断 | 观察 2.25 秒；Codex 子进程 RSS 采样峰值 76.39 MiB；诊断成功并正常退出 |

短时观察不能代表长期功耗或所有机型。RSS 包含驻留的共享页面，不等同于独占物理内存。额度诊断包含 1 秒系统差分采样；它与 GUI 常驻测量属于两次不同运行，不能直接当作同一次运行的总峰值。子进程峰值为按 100 毫秒间隔采样得到的观察值。

公开测量记录：[后台测量](performance-idle.json)、[一次额度诊断的资源测量](performance-quota-read.json)。资源采样保留原值；额度诊断仅保留成功状态，账户额度、恢复时间、重置卡和系统诊断明细已移除。完整原始记录保留在迁入前的本地源项目。
